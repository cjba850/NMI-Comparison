TOU periods

Each period can be limited by days and months. Days: Mon=0, Tue=1, Wed=2, Thu=3, Fri=4, Sat=5, Sun=6. Months: Jan=1 through Dec=12. Leave Months blank for all months. Overnight periods are supported.

Applied once for each calendar month represented by the uploaded data.

Controlled load (optional)

CL1/CL2 rates can be stored here. They are only charged when the meter import contains separate controlled-load kWh. Your current import format does not split CL1/CL2 consumption, so configured rates will be reported but not applied.
